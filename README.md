# MOHSEN - شبیه‌ساز کامل LOGO! Soft Comfort

- تم کلاسیک و رنگ‌بندی استاندارد زیمنس LOGO! Soft Comfort (بلوک‌های زرد ورودی، سبز خروجی، طوسی گیت‌ها و فیروزه‌ای توابع ویژه).
- سیم‌کشی آسان لمسی بین بلوک‌ها + تست و شبیه‌سازی زنده (F3) با تغییر رنگ سیم‌ها.
- تبدیل خودکار نقشه FBD به نردبانی (LAD) + اسیلوسکوپ نمودار زمانی (SCOPE).
- شامل تمامی مدارهای کتاب طراحی و اجرای رله‌های قابل برنامه‌ریزی (۲۱۲۲۶۶).
